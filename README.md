# Brightside Design

## Navigation behavior

The homepage and Services page use the same primary-navigation labels and layout. From Services, each standard navigation link returns to its matching `index.html` section anchor.

The mobile navigation's Contact us button is the only exception: it copies `brian@brightsidelb.com` and scrolls to the Services-page contact section. It intentionally does not show the navigation's `COPIED!` tooltip; copied feedback is shown by the destination contact CTA instead.
